# MINOS — site vitrine e sistema de gestão

Projeto de uma marca de camisetas fit inspirada no Minotauro (*"Entre no labirinto."*), do conceito ao site no ar: identidade visual, vitrine, plano de validação de mercado e uma base de gestão.

## Estrutura

```
index.html            site vitrine
css/styles.css        estilos e tema claro/escuro
js/main.js            seleção de tamanho e pedido por WhatsApp
gestao/index.html     sistema de gestão (dados salvos no navegador)
assets/images/        mockups das camisetas (frente e costas)
assets/video/         vídeo comercial e poster
```

## Antes de publicar

1. Adicione as imagens em `assets/images/` (`touro-marinho.jpg`, `touro-branco.jpg`, `touro-militar.jpg`, `touro-grafite.jpg`, `costas-preta.jpg`, `costas-branca.jpg`) e o vídeo em `assets/video/minos-comercial.mp4` + `poster.jpg`.
2. Troque `NUM` em `js/main.js` pelo WhatsApp real (DDI + DDD + número, só dígitos).
3. Atualize `@suamarca` no rodapé do `index.html` quando criar o Instagram oficial.
